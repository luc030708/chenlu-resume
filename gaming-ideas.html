关于这个灵感区

除了拆解别人的游戏，我也有自己想做的游戏。《归乡》（Coming Home）是我独立撰写的一份完整游戏立项方案——一款关于离家、想家与和解的叙事探索游戏。从题材判断、玩法循环、美术音乐，到市场对标、发行节奏、预算与风险，都用真实的立项标准完整跑了一遍。它代表我对「游戏作为内容产品」的完整思考方式：不只看到玩家情绪，也算得清商业模型。

玩家扮演一位孤独离世的城市独居者鬼魂，死前唯一的执念是「回家」。在无法被任何人看见的状态下，通过触碰物品唤起记忆，逐步拼凑出「自己为什么离开」「家在哪里」「家是否还存在」的答案。 一句话定义 · ONE-LINER

核心价值主张

  • 品类突破：华语市场首款正面处理「孤独死」与「当代城乡断裂」议题的叙事游戏。
  • 情感通约：「想家」是跨语言、跨文化的人类共通情感，具备天然的全球市场基础。
  • 市场空白：国内剧情向赛道集中于乙女、悬疑恐怖、历史神话，当代现实题材几乎空白。
  • 传播友好：设定一句话可讲清，记忆闪回机制天然适合短视频和社交媒体二创传播。

故事背景与主角

故事发生在 2020 年代后半段的中国一线城市——独居青年比例迅速攀升、空巢老人急剧增加、城市与乡村之间的情感联系日益稀薄的时代。「孤独死」（Kodokushi）在日本已有三十余年的社会讨论，中国正在经历类似的人口结构变化，但这一议题在文化产品中尚未被严肃处理。《归乡》试图填补这一文化空白。

  • 林越（暂定）：男 / 女性别可选，33 岁，互联网公司中层员工，独居在城市边缘的老式出租公寓。
  • 家乡：中国某南方县城（名称在游戏中逐步揭示），父亲早年去世，母亲独居老家。
  • 死亡情境：突发心脏骤停，死在出租屋里，从死亡到被发现间隔约一周。
  • 执念：回家。但「家」对他/她而言已是一个模糊的、被多年回避的概念。

世界观规则

《归乡》不是恐怖游戏，也不构建复杂的鬼神体系。「鬼魂」设定服务于一个核心叙事目的——让玩家以无力干预现实、只能借助物品进入记忆的方式，体验「回望自己一生」的感觉。

鬼魂能做的事

  • 自由移动于死亡时所在的物理空间（出租屋为起点，逐步扩展）；
  • 触碰物品并触发与该物品相关的记忆碎片；
  • 观察现实世界（房东、邻居、警察、清洁工等他人的反应）。

鬼魂不能做的事

  • 被任何活人看见、听见或感知到；
  • 移动或干预现实中的物体；
  • 直接「想起」任何事情——所有记忆都必须由物品触发。
同一件物品在游戏不同阶段被触碰，会触发不同版本的记忆。我们看待过去时，看到的从来不是过去本身，而是当下的自己所能承受的那个版本。 核心设定 · 记忆的不可靠性

玩法系统设计

核心循环（极简，服务于叙事沉浸）

  • 探索 Explore：第一人称自由穿行（出租屋、楼道、便利店、地铁、车站、记忆中的老家）；
  • 触碰 Touch：靠近可交互物品时屏幕边缘泛起光晕，按键触碰进入记忆；
  • 回忆 Remember：以观察者视角体验一段过去——一段对话、一个场景、一个画面；
  • 拼合 Connect：记忆碎片在「回忆图谱」中自动归位，逐步构建完整的家庭叙事；
  • 解锁 Unlock：关键记忆拼合后，新的物理空间或记忆维度开放。

机制一：物品的多层记忆（以「妈妈寄来的毛衣」为例）

阶段玩家心境毛衣触发的记忆
早期还在抗拒「妈妈寄来的，嫌它土气，塞进了柜子最底下，从来没穿过」
中期开始动摇「那年她身体已经不太好了，是撑着去市场挑的料子」
后期终于直面「我其实一直知道她身体不好。我只是假装不知道」

机制二：回忆图谱

成就感不来自分数或经验值，而来自一张逐渐填满的「回忆图谱」（Memory Map）：每段记忆是一个节点，关联自动连线，视觉风格类似手绘家族关系图，带水墨晕染感。

机制三：无 UI 沉浸

主体验不显示传统 UI（无血条、无任务列表、无小地图），引导通过光线、声音、视觉焦点完成，参考《Journey》《Gris》《Inside》。

机制四：空间的逐步开放（五个阶段）

  • 出租屋内部（死亡现场）→ 楼道与小区（被他人发现的过程）→ 城市里常去的地点（便利店、加班的办公楼、相亲的咖啡馆）→ 返乡路途的记忆化场景（火车窗外、永远到不了的站台）→ 童年的家（最核心的情感场景，后段开放）。

主线流程 8–10 小时（对标《What Remains of Edith Finch》《Gone Home》），完整收集 12–15 小时；二周目同一物品触发未见过的记忆变体。

艺术风格与音乐设计

  • 美术方向：低饱和度写实 + 意象化记忆场景。现实空间写实建模但色调压低、光线偏冷；记忆场景带颗粒感与水彩晕染——「被回忆过滤过的真实」。参考《Gris》的色彩情绪、《Edith Finch》的空间叙事、《Spiritfarer》的温柔笔触、贾樟柯的镜头语言。
  • 中式元素：不刻意符号化（不要春节红、龙凤、青花瓷），从空间细节入手——南方县城湿润斑驳的墙面、公寓楼道堆放的旧物、出租屋窗外晾晒的衣物、地铁里沉默的乘客。
  • 音乐：极简钢琴 + 弦乐小编制 + 环境音，作用是「拉开情绪空间」而非「提示此处该感动」。
  • 环境音：楼上隔壁的电视声、楼下的车响、深夜冰箱的嗡鸣、母亲在厨房锅铲翻动的声音——高度写实的环境音是关键沉浸要素。
  • 配音策略：中文为主配语言，母亲角色使用主角家乡方言；海外版字幕 + 保留方言原声，控制成本同时保留文化质感。

市场分析与商业模型

核心用户画像

25–38 岁，女性 55% / 男性 45%；国内一二线城市 + 海外日韩北美西欧大城市；Steam 独立游戏与叙事游戏爱好者，有文学、电影、播客消费习惯（是枝裕和、贾樟柯、Pixar）；有过离家求学/工作经历，与父母关系复杂，对「孤独」「漂泊」议题敏感。

销量预期与回报测算

  • 保守估算：全球首发 15–30 万份，长尾累计 50–80 万份；
  • 首发定价 68–98 元，综合长期折扣后平均到手价约 40 元/份；
  • 流水预期：保守 2000 万 / 中性 3200 万 / 乐观 5000 万+，对 1000 万投入是合理回报区间；
  • 渠道分成：Steam / 主机平台各 30%，实际净收入按流水的 60%–65% 估算。

发行策略

发行节奏（全球同步）

  • T-18 个月：首支预告片公开，Steam 页面上线开放愿望单，启动核心社区（Discord、微博、X）；
  • T-12 个月：参展 BitSummit（京都）、WePlay（上海）、Gamescom（科隆），释出试玩 Demo；
  • T-6 个月：Steam Next Fest 集中爆发，启动文化媒体公关期；
  • T-3 个月：媒体审查版本送达 IGN、Polygon、Eurogamer、4Gamer，准备 KOL 物料；
  • T-1 周：完整发售预告 + 社媒最终预热；T+3 个月：首次大幅折扣，主机版本同步上线。

媒体矩阵：文化议题驱动破圈，而非游戏媒体铺量

  • 中文：单读 / GQ 报道 / 三联生活周刊 / 新周刊（切「孤独死」「独居青年」议题）→ B站影视区、小红书情感博主 → GameRes / Indienova →《忽左忽右》《故事FM》播客；
  • 海外：The New Yorker / The Atlantic / Vox（亚洲家庭议题）→ Polygon / Eurogamer / RPS（叙事评论）→ 4Gamer / Famitsu（日本市场对家庭叙事高度敏感）→ YouTube 独立游戏推荐频道。

内容营销三大钩子

钩子一 · 一句话传播「一个孤独死去的鬼魂，最后的执念是回家」
钩子二 · 机制悬念「同一件物品，你看它三次，它会变成三段不同的回忆」
钩子三 · 情感号召「玩完这款游戏，你想做的第一件事，是给妈妈打个电话」

过审策略（双轨）

  • 海外优先：首发以海外 Steam + 主机为主，保留完整艺术表达；
  • 国内适配：「鬼魂」调整为「弥留意识」「记忆体」等表达，参考《烟火》将超自然元素现实化的处理；
  • 提前沟通：立项阶段即与版号代办机构沟通，识别审查重点。

IP 长期价值开发

  • 小说化（扩展未展开的支线）· 短剧/微电影改编（反哺长尾销售）·「物品与记忆」主题展览 · 原声带 + 环境音氛围专辑——让 1000 万产出的不只是游戏，而是可延展的内容资产。

立项结论

《归乡》的商业逻辑不是赌爆款，而是三个核心价值的叠加：产品价值——以「孤独死的鬼魂回家」这一极具情感冲击力又适合一句话传播的设定，切入华语剧情向赛道未被覆盖的当代现实题材；战略价值——补齐叙事品类的研发与发行能力，积累海外买断制的口碑资产和渠道经验；文化价值——首次以游戏媒介认真处理华语世界的「孤独死」与「代际情感断裂」议题，具备进入主流文化讨论的潜力。

在买量成本高企、版号收紧、用户审美升级的环境下，1000 万不应该是用来赌爆款的钱，而应该是用来投资「未来做更大项目时的能力底气」的钱。我们想做的，是一款「小而准」的游戏：用现实情绪切入市场空白，用精品表达建立长期口碑，用全球化发行放大文化影响。 立项结语 · PITCH CLOSING
